Place Family

Place Revit families using geometry from linked model elements

PF
Place
Family

What this tool does:

Place Family places the selected Revit family type onto elements from a linked model.

In the current workflow, the tool:

  • asks you to choose a target family and type,
  • asks for the linked structural family name to search for,
  • asks you to select a linked model,
  • places one new family instance at the top midpoint of each matching visible linked element.

This is useful for placing devices, markers, or coordination content on repeated linked elements such as beams.

Before you start:

Make sure the following are true before running the tool:

  • A Revit model is open.
  • You are in a 3D view.
  • A linked model is loaded.
  • The linked elements you want to use are visible in the active view.
  • The family you want to place is a One Level Based family.
  • You know the family name of the linked elements you want to target.

Example linked family name: AMX-S-Beam-Steel-Rectangular_HSS

How to use the tool:

  1. Open a 3D view
    Open the 3D view where you want the tool to look for linked elements.
    The tool will not run from a non-3D view.
  2. Start the command
    On the ribbon, click Place Family.
  3. Select the family to place
    Choose the Revit family you want to place.
    If the family has more than one type, you will be asked to choose the specific type.
  4. Enter the linked family name
    When prompted, type the family name of the linked elements you want to target.
    This must match the family name used in the linked model.
  5. Select the linked model
    Choose the Revit link that contains the target elements.
  6. Let the tool place the instances
    The tool will search the selected link for matching structural framing elements and place the selected family type at the top midpoint of each match.

What the tool places:

For each matching linked element, the tool:

  • finds the element midpoint,
  • finds the top of the element,
  • converts that point into the host model,
  • places the selected family instance at that location,
  • assigns the nearest level in the host model.

Expected result:

After the command finishes, you should see new family instances placed on the matching linked elements in the active model.

Tips for best results:

  • Use a clean 3D view with only the relevant linked elements visible.
  • Confirm the linked family name before running the tool.
  • Use a family that is intended to be placed by point.
  • If no elements are found, first check visibility, link selection, and spelling of the linked family name.

Troubleshooting:

Activate a 3D view and try again.

Open a 3D view, then run the command again.

Selected family/type must be OneLevelBased for Control Mode.

Choose a different family type. The selected family must support point placement.

No structural framing elements of family '...' found in the linked model.

Check:

  • the linked model you selected,
  • the exact linked family name,
  • whether the target elements are structural framing elements.

No visible structural framing elements found in the active view.

The elements may exist in the link, but they are not visible in your current view.

Try:

  • opening another 3D view,
  • turning on the relevant categories,
  • checking view filters, worksets, and link visibility settings.

Nothing was placed

Possible causes:

  • no matching linked elements were found,
  • the selected family type is not valid for this placement method,
  • the view does not show the target linked elements.

Simple example:

Use this tool when you want to place the same family on every matching beam from a linked structural model.

Example workflow:

  1. Open a 3D coordination view.
  2. Click Place Family.
  3. Select your device family.
  4. Select the type to place.
  5. Enter the linked beam family name.
  6. Pick the linked structural model.
  7. Review the placed instances.

Notes:

This tool places instances in the current model based on geometry found in the selected linked model. It does not modify the linked file.
