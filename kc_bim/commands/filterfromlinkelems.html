FF
Filter
From Linked Elements

What this tool does:

Create a view filter of the IfcGUIDs of the selected linked elements. This filter can be applied to desired views and VTs to control visibility of linked elements like Equipment, Fixtures, Generic Models, etc. NOTE 1: Important! Set RVT Link Display Settings> View filters: By host view!!!! NOTE 2: For controlling filtering/visibility of elements like ducts, pipes, conduits, fittings, accessories, etc: Select linked elements>Right Click menu>Hide In View>Elements or use HideLinkElements" command.

How to use the tool:

  1. [250912] created, 250918 (Updated to OR filter (not AND) for selecting multiple elements ie Cable tray and fittings)

Best use case:

Use Filter From Linked Elements when you need the workflow described above and want a faster, repeatable command instead of manually processing the same Revit task.
