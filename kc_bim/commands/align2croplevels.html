Align 2 Crop - Levels

Align selected levels to the active view crop region by updating each level's view-specific curve

Source command: Cmd_Align2CropLevels

A2C
LVL
Align
Levels

What this tool does:

Aligns selected levels to the active view crop region. The command validates the current view, ensures the crop box is visible, reads the crop boundary, offsets the boundary slightly, and applies the resulting curve to each selected level in view-specific mode.

How to use the tool:

  1. Activate a plan, section, or elevation view with a crop region.
  2. Select one or more levels in the model or in the view.
  3. Run Align 2 Crop - Levels.
  4. The tool checks for temporary view mode and cancels if the view is not suitable.
  5. The crop box is made visible if needed.
  6. The crop boundary is read and offset slightly.
  7. Each selected level is updated to match the crop boundary in the active view.

Best use case:

Use Align 2 Crop - Levels when level extents need to match a cropped view for cleaner annotation, documentation, or view control.

Behavior summary:

  • Uses the selected levels only.
  • Works with the active view crop region.
  • Skips unsupported temporary view states.
  • Applies view-specific level curves using Revit datum controls.

Additional features:

View safety check

Stops if the active view is in temporary mode to reduce failed edits and inconsistent results.

Crop visibility support

Automatically turns on the crop box before reading the crop boundary.

Offset boundary handling

Attempts to offset the crop shape before applying it to levels for cleaner alignment.

Notes and requirements:

  • The active view must support a crop region.
  • One or more levels must be selected before running the command.
  • Results depend on the view type and crop shape geometry.
