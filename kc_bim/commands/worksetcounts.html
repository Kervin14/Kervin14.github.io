Workset Counts

Analyze category distribution in a selected workset, or hold Shift to find empty worksets.

Source command: Cmd_WorksetCounts

WC
Workset
Counts

What this tool does

Provides workset-level element analysis for BIM management workflows.

  • Normal mode: Select one workset and return element counts by category.
  • Shift mode: Find user worksets with zero elements (excludes Workset1).

How to use

  1. Start command
    Click Workset Counts from the Analyze section.
  2. Choose mode
    Run normally for category counts, or hold Shift when launching to run empty-workset detection.
  3. Review output
    Read the completion dialog for counts and recommendations.

Safety logic

If the selected workset is large, the command estimates runtime and warns before continuing when likely to exceed ~2 minutes.

Notes

Requires workshared model.

Empty-workset scan intentionally excludes Workset1 (default workset).

Progress is shown using the internal progress coordinator and can be cancelled.
