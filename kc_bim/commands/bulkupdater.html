Bulk Updater

Easily upgrade and multi-process selected Revit files (.rfa, .rvt, .rte, etc)

Source command: BulkFiles_BulkUpdater

BU
Bulk
Updater

What this tool does:

Easily upgrade and multi-process selected Revit files (.rfa, .rvt, .rte, etc). Files are upgraded behind the scenes and saved to a new folder (which opens at the end of the process). Models are opened with all worksets closed. Options enabled include: Audit and Detached and preserve worksets. Files are saved as a new central model if it's workshared, or just saves if not. Save-as enabled options: Compact and Maximum Backups = 100. Finally files are closed without saving to apply the upgrade. Families are similarly upgraded but without the open options and saved in a new folder. This command is available even if a project is not opened. 260210: Aligned to python node in Dynamo (Provided by Bachir) and added All Worksets Closed to open options. Updated description.

How to use the tool:

  1. Start the command
    Click the tool button in the Revit ribbon.
  2. Follow the prompts
    Respond to the selection dialogs or input prompts shown by the tool.
  3. Review the result
    Check the active model or output message after the command finishes.

Best use case:

Use Bulk Updater when you need the workflow described above and want a faster, repeatable command instead of manually processing the same Revit task.

Additional features:

Shift Mode

Shift + Click: Include subfolders during file search. No dialog, as modifiers are more intuitive and faster.
