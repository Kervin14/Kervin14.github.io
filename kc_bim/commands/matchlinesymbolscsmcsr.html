Symbols CSMC SR

What this tool does:

Customized for Cedars SR having sheet numbering pattern 'EL206iN1' 'EE108iN1' etc. For faster execution: Close Link worksets and use a keyboard shortcut (ie ;;") Select source sheet viewport with matchline symbols and run the command. Copies the symbols from the selected source viewport to all target sheets having views with the same scope box. Then updates the symbols' text parameter ("Sheet_Num") values in the target sheets based on the sheet number. Additional cleanup: deletes duplicates and clears param values for symbols in Non-Issued sheets. Original location for generic annotation family: C:\Users\kervin.calero\Revit_task\VSC Projects\pythonProject\KC-Tools.extension\KC-Tool.tab\Sheets.panel\col3.stack\sheet refs.pulldown\SheetRefs_BatchCopy.pushbutton\SheetReferenceSymbol.rfa' 260116: Merged to a single command and updated documentation. 260117: Separated control mode to its own command for easier access and updated documentation. 260515: Updated description. _________________________________________________________________"

  3. Review the result

Best use case:

Use Matchline Symbols CSMC SR when you need the workflow described above and want a faster, repeatable command instead of manually processing the same Revit task.

Additional features:

Shift Mode

Shift + Click: Collects and deletes all existing empty symbols document wide (no selection required).

Alt Mode

Alt + Click: Deletes symbols on target sheets having views with the same scope box.

Notes and requirements:

Assumptions: -The symbol text param 'Sheet_Num' has been populated for the source sheet and all target views have the same scope box. -The symbol generic annotation family has been loaded to the project, the matchlines workset is opened, current, and visible in the sheet v/g settings.
