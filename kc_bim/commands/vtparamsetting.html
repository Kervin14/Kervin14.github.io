VTparam Setting

Batch-set view template parameters for selected view templates. Currently only supports: Detail Level, View Scale

Source command: VTs_VTparamSetting

VS
VTparam
Setting

What this tool does:

Batch-set view template parameters for selected view templates. Currently only supports: Detail Level, View Scale, and View Range offsets. Select one or more view templates, Detail Level: Apply a unified detail level across selected view templates. All selected templates will use the same detail level. View Scale: Apply a unified view scale across selected view templates. All selected templates will use the same view scale. View Range offsets: Adjust Top, Cut, Bottom, or View Depth offsets (templates always use Associated Level). Non‑plan templates are skipped automatically.
