Select My Views

Efficiently select multiple views in the Project Browser for batch operations

Source command: Views_SelectMyViews

SM
Select
My Views

What this tool does:

Efficiently select multiple views in the Project Browser for batch operations. For single view selection right click in the canvas and Find In Project Browser" 260317 - Added modes for selecting placed/not placed views and updated description. 260628 - Added support for schedules, updated versioning, and updated description. 260731 - TODO: Select only Primary/parent views, dependent, or independent"

How to use the tool:

  1. Batch renaming views.
  2. Tagging
  3. Applying view templates.
  4. Applying or updating view templates.
  5. Modifying view parameters for multiple views at once.
  6. Quickly locating and managing specific views in large projects.

Best use case:

Use Select My Views when you need the workflow described above and want a faster, repeatable command instead of manually processing the same Revit task.

Additional features:

Shift Mode

Shift + Click: Select from a list of views that are sheeted (placed on a sheet)

Ctrl Mode

Ctrl + Click: Select from a list of views that are not sheeted (not placed on a sheet)
