Save As

Equivalent to the Save As" button in the UI

Source command: Modify_Saveas

SA
Save
As

What this tool does:

Equivalent to the Save As" button in the UI. Assign keyboard shortcut since the Revit OOTB Save-As cannot have a keyboard shortcut assigned! Default mode: Saves a copy of the current Revit model as a new central file in a user-selected location. Enables worksharing, configures all worksharing options, and syncs with central. 260501: Added more save/sync features and updated description. 260502: Added shift mode (basic save-as) and updated description. 260520: Added ctrl mode (family save-as) and alt mode (extract family from project). Updated description."

How to use the tool:

  1. Cloud Model to Local Network Migration
  2. Saves an Autodesk Construction Cloud (ACC) model to a local network drive or file server
  3. Useful when transitioning projects from cloud to on-premise storage
  4. Project Backup/Archive
  5. Creates a standalone copy of a workshared model in a backup location (e.g., Downloads folder)
  6. Preserves the model as a new central file with full worksharing capabilities
  7. Model Duplication for Testing
  8. Creates a separate copy of an existing central model for testing changes or conducting analyses
  9. Maintains worksharing structure while isolating experimental work from the production model

Best use case:

Use Save As when you need the workflow described above and want a faster, repeatable command instead of manually processing the same Revit task.

Additional features:

Shift Mode

Shift + Click: Performs a simple, non-workshared save-as operation - perfect for creating standalone local copies without worksharing overhead.

Ctrl Mode

Ctrl + Click: Saves an already-open family document (.rfa) to a new location with a simple save-as operation. Use this when you have a family open and want to save it to a different location.

Alt Mode

Alt + Click: Note: You can also use the "Save Family" custom command instead of this mode. Extracts a family from the current project document. Prompts to select a family file (.rfa), loads it into the project, then saves it to a new location. Use this to create standalone copies of families embedded in projects.
